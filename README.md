## 使用指南

应用分为三个选项卡：番茄记录、项目管理，和历史番茄。

### 1. 番茄记录

- 记录当日工作/学习项目，投入的番茄数。
- 备注栏可以简单写一下具体做了什么，以及进度停在了哪里，方便下次衔接。
- 添加桌面快捷方式。

### 2. 项目管理

- 查看、搜索、编辑自己过往投入过的所有工作/学习项目。
- 为低优先级的项目标记完成或归档，明确当下重心。
- 为项目打上标签，方便搜索和统计。
- 为项目写笔记，记录自己的初心和规划。

### 3. 番茄历史

- 查看、搜索、编辑过往番茄记录。
- 通过导出/导入 csv 按钮备份/恢复数据。

## 使用案例

### 工作

项目名称：xx应用，备注：跑通xx，尝试xx，在项目管理中将该项目打上“应用开发”标签

### 爱好

项目名称：正念冥想，备注：空，在项目管理中将该项目打上“健康”标签

### 阅读

两种记录方式：
1. 项目名称：阅读，备注：《xxx》P15。可以在项目管理-项目笔记中写下其他书籍阅读计划。
2. 项目名称：《xxx》，备注：P15，在项目管理中将该书打上“阅读”标签。有排队中的阅读计划，可以在项目管理中新建书籍项目。

### 学习

两种记录方式：
1. 项目名称：机器学习，备注：B站xx视频系列2/130，13:23，在项目管理中将该项目打上“AI”标签，其他项目（如深度学习、NLP）也可以打“AI”标签
2. 项目名称B站xx视频系列，备注：2/130，13:23，在项目管理中将该项目打上“AI”“机器学习”标签，其他同主题课程或者Kaggle练习也可以打上“机器学习”标签
